# Training video materials

Three screen-recorded training videos for ARAL LitTrack, one per audience:

| Module | For | Runtime |
|---|---|---|
| 1 | School heads — the one-time school setup | ~12–14 min |
| 2 | Teachers — accounts, learners, ARAL, attendance, reading level | ~15–17 min |
| 3 | Non-DepEd ARAL volunteers, and the teachers who assign to them | ~8–9 min |

All three are recorded in one continuous session — the account state builds from an empty school
to an assigned volunteer — and split into three videos in the edit.

| File | What it is |
|---|---|
| `aral-training-video-script-v2.md` | **The script to record from.** Checked against the app. |
| `screenshot-capture-checklist-v2.md` | The 19 manual stills, each pulled from a video take. |
| `aral-recording-plan.md` | Take order, account state, one-shot takes, per-part timings. |
| `chatcut-handoff.md` | ChatCut setup, sequencing, and the brief to paste into it. |
| `script-app-audit.md` | What v1 got wrong about the app, with code citations. Read once. |
| `aral-training-video-script-v1.md` | Original draft. Kept for provenance — do not record from it. |
| `screenshot-capture-checklist-v1.md` | Original checklist. Same. |

## Order of work

1. Read `script-app-audit.md` §A — three things v1 asked for are impossible, and knowing why
   saves an argument on set.
2. Provision a demo school (Super Admin → settings → demo tenant). Keep one of the three demo
   schools in reserve for retakes of the one-shot parts.
3. Record the takes in the order in `aral-recording-plan.md`.
4. Pull the 19 stills from the footage.
5. Hand takes + script to ChatCut per `chatcut-handoff.md`.

## Keeping this accurate

The script names real menu labels, field names, and button text. Any UI change to sign-in,
profiling, the learner form, ARAL enrolment, or the two ARAL grids dates it. `script-app-audit.md`
cites the file behind each claim, so a re-check is a read, not an investigation.
